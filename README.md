# Reiko's Weather downloads

Built mod files for Minecraft 1.21.1 with NeoForge 21.1 or later. The source code is on the `main` branch.

- `reikos_weather-1.28.0.jar` (latest: detailed 64x textures for the tornado siren, storm probe, weather altar, icebox, rain barrel and forecast board too): put it in your `mods` folder (on a server, install it on the server and on every player's game).
- `reikos_weather-1.27.0.jar`: detailed, realistic 64x textures for the weather station, weather radar, lightning battery and seismograph.
- `reikos_weather-1.26.0.jar`: place the windmill facing any way, and new textures for the weather station, weather radar, lightning battery and seismograph.
- `reikos_weather-1.25.0.jar`: meteors in four sizes, from small pebbles to rare huge fireballs.
- `reikos_weather-1.24.0.jar`: everything in its own Reiko's Weather creative tab, and 3D models for every item.
- `reikos_weather-1.23.0.jar`: tornado shapes, multiple-vortex, satellite and rain-wrapped tornadoes, tornado families and outbreak days.
- `reikos_weather-1.22.0.jar`: tornadoes touch down weak, strengthen through the EF ratings and rope out.
- `reikos_weather-1.21.0.jar`: tornadoes rated EF0 to EF5.
- `reikos_weather-1.20.4.jar`: lighter fog, and a Fog Strength setting.
- `reikos_weather-1.20.3.jar`: no more night beeping, much stronger tornadoes, the glory fixed.
- `reikos_weather-1.20.2.jar`: fixes for storm clouds, rain shafts, light pillars, sunbeams and the moon's halo.
- `reikos_weather-1.20.1.jar`: no more red skies and fire whirls from underground fires, a natural snow squeak.
- `reikos_weather-1.20.0.jar`: volumetric clouds, tornadoes that lift you, one quake per `/rweather quake`.
- `reikos_weather-1.19.1.jar` (previous): put it in your `mods` folder (on a server, install it on the server and on every player's game).
